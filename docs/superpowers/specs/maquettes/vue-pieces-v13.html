v13 — pièces placées pour que les liens les évitent, navigation entre pièces, vue par pièces au dézoom

Base v12. Les pièces se placent de façon à limiter les liens qui passent sur une autre pièce ou qui se croisent. En pièce isolée, clic sur une autre pièce : on y va ; clic à côté : on revient. Au dézoom extrême, vue par pièces sans noms d'appareils.

v13 · molette : zoom · glisser le fond : déplacer la vue · clic sur une pièce : l'isoler, puis clic sur une autre : y aller, clic à côté : revenir · glisser une pièce : la déplacer · Échap : revenir
